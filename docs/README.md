# WildGent Documentation

This repository separates product/design references from internal implementation knowledge.

- [Game Design Reference](./GAME_DESIGN.md) defines the experience, MVP scope, and non-negotiable
  product principles.
- [Hackathon Implementation Specification](./SPEC.md) defines the intended contracts and acceptance
  criteria for the vertical slice.
- [Internal knowledge index](./knowledges/README.md) is the code-grounded guide for contributors and
  coding agents. It is synchronized from executable source, configuration, and tests.

When implementation and a product reference disagree, verify the current source and tests first,
then record the discrepancy in the knowledge pack or update the product document deliberately.
